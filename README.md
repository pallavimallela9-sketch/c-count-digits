# Count Digits

This program counts the number of digits in a given number.

## Features

* Takes a number from the user
* Counts its digits
* Displays the total number of digits

## Technology Used

* C

## Concepts Used

* Variables
* While loop
* Integer division
* Conditional statements

## Sample Output

```text
Enter a number: 12345
Number of digits: 5
```
